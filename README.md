# Martina Monti — Personal Website

Personal portfolio and professional website of **Martina Monti**, focused on Mathematics, Data Science, Data Engineering and Cloud Solutions.

🌐 **Live website:** [https://montimartina.github.io](https://montimartina.github.io)

## Website

The site is a static website published with **GitHub Pages**.

- `index.html` — homepage, profile, background, skills and projects.
- `work.html` — work experience, education and certifications.
- `assets/css/main.css` — custom site styles.
- `assets/js/main.js` — interactive behaviour and theme handling.
- `assets/img/` — profile images and site icons.
- `Martina_Monti_CV.pdf` — downloadable CV.
- `TOEIC.pdf` — language certificate.

## Local preview

No build step is required.

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the folder with a local static web server.
3. Navigate to `work.html` to view the experience and education page.

Some visual assets and libraries are loaded from external CDNs, so an internet connection may be required for the complete experience.

## Deployment

The website is published from the repository's `main` branch through GitHub Pages. Changes pushed to that branch are published by GitHub Pages automatically.
